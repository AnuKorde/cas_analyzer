# AI Guardrails and Restrictions

**Document Version:** 0.1

**Status:** Draft

**Last Updated:** 2026-08-29

## 1. Purpose

This document defines the strict boundaries for AI usage, protecting both the development process and the end-user product.

## 2. Product Guardrails (What AI cannot do in the App)

As per the project scope, Version 1 of CAS Analyzer **excludes** generative AI features for the end user.
- **No AI Investment Advice:** The app must not use LLMs to generate personalized financial advice, portfolio summaries, or chat interfaces for the user. All recommendations must be deterministic and rule-based (see `05_BusinessLogic/04_RuleBasedRecommendations.md`).
- **Offline First:** The app cannot rely on cloud-based AI APIs (like OpenAI) at runtime, as this violates the offline-first privacy guarantee.

## 3. Development Guardrails (What Developers cannot do with AI)

- **No PII in Prompts:** Developers must **never** paste real CAS PDF text, real names, PAN numbers, or actual portfolio data into cloud-based LLM prompts (e.g., ChatGPT web interface). All text snippets used for generating regex or parsers must be heavily sanitized and synthetic.
- **No Blind Trust in Math:** AI models are notoriously poor at exact arithmetic. Any financial calculation code generated by AI must be meticulously verified via unit tests with manually calculated expected results.
